ไอคอนบนหน้าจอ / Desktop shortcut

  • อัปโหลดใหม่แล้ว ในเว็บ (navbar, หน้า login) จะเปลี่ยนทันที
  • Shortcut ที่ user บันทึกไว้แล้ว มักยังเป็นรูปเก่า — Windows/มือถือ cache ตอนติดตั้ง
  • ให้ user ลบ shortcut เก่า แล้วติดตั้งใหม่จาก Chrome/Edge (เมนู → ติดตั้งแอป / Add to Home Screen)
  • โลโก้ PTA/PT4/PTE ใช้ใน navbar ตามบริษัท — ไม่กระทบไอคอนแอปหลัก
