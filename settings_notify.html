Notification Routing — LINE / Telegram
ตั้งค่า LINE Token ตั้งค่า Telegram Token
ระบบ Routing แจ้งเตือน — กำหนดว่า event ไหนจะส่งไปยัง Channel ไหน
เพิ่มหลาย Channel ได้ เช่น IT Group (Telegram), Stock Admin (LINE), แม่บ้านGAใช้ (LINE อีกกลุ่ม)
ถ้ายังไม่มี Channel ระบบจะใช้การตั้งค่าเดิมจากหน้า LINE / Telegram Settings โดยอัตโนมัติ
วิธีตั้งค่า LINE / Telegram ใหม่แต่ละ Group (คลิกเพื่อดู)
LINE — วิธีเพิ่ม Group ใหม่
  1. สร้าง Group ใหม่ใน LINE App
  2. เพิ่ม Bot เข้า Group (Bot อยู่ใน settings_line.html)
  3. เพิ่ม @getidsbot เข้า Group → มันส่ง Group ID มาให้ → kick ออกได้
  4. Copy Token จาก settings_line.html
  5. กด "เพิ่ม Channel" → เลือก LINE → วาง Token + Group ID → เลือก Events → บันทึก
💡 Token เดียว ใช้ได้ทุก Group ไม่ต้องสร้าง Bot ใหม่
Telegram — วิธีเพิ่ม Group ใหม่
  1. สร้าง Group ใหม่ใน Telegram
  2. เพิ่ม Bot เข้า Group (Bot Token อยู่ใน settings_telegram.html)
  3. เพิ่ม @userinfobot หรือ @getmyid_bot เข้า Group → ได้ Chat ID (ติดลบ เช่น -1001234567)
  4. Copy Bot Token จาก settings_telegram.html
  5. กด "เพิ่ม Channel" → เลือก Telegram → วาง Token + Chat ID → เลือก Events → บันทึก
💡 Bot Token เดียว ใช้ได้ทุก Group เช่นกัน
