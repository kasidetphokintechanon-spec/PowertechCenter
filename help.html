เริ่มใช้งาน

ทุกอย่างอยู่ในเว็บเดียว ใช้ได้ทั้งคอมและมือถือ

  1. เข้าเว็บ Powertech Center แล้ว ล็อกอินด้วยรหัสพนักงาน และเลือกบริษัทที่สังกัด
  2. หน้าแรกมี ปุ่มลัด 4 ปุ่ม ด้านบน: แจ้งซ่อม IT · ยืมอุปกรณ์ · จองห้องประชุม · หาเบอร์เพื่อน
  3. กล่อง "งานของฉัน" ทางขวา บอกสถานะเรื่องที่คุณแจ้ง/ยืม/เบิกไว้ทั้งหมด — กดเพื่อดูรายละเอียด
  4. เมนูซ้าย "ของฉัน" รวมประวัติแจ้งซ่อม ยืม และเบิกของ
บนมือถือ: เปิดเว็บใน Chrome / Edge แล้วกด "เพิ่มลงหน้าจอหลัก" จะใช้งานเหมือนแอป

แจ้งซ่อม IT

คอมเสีย ปริ้นเตอร์ไม่ทำงาน เน็ตหลุด ขอติดตั้งโปรแกรม — แจ้งทางนี้ ทีม IT เห็นทันที

  1. หน้าแรก กด "แจ้งซ่อม IT"
  2. เลือก มีปัญหาเรื่องอะไร (คอมพิวเตอร์ ปริ้นเตอร์ เน็ต โปรแกรม ฯลฯ)
  3. เลือก อยู่ที่ไหน และ เครื่องไหน — ถ้ามีสติกเกอร์ QR บนเครื่อง สแกนได้เลย ระบบรู้ว่าเป็นเครื่องไหน
  4. เล่าอาการสั้น ๆ แนบรูปหน้าจอ error ได้ แล้วกดส่ง
  5. ติดตามที่แท็บ "งานของฉัน": รอรับเรื่อง → กำลังซ่อม → รอคุณยืนยัน
  6. ช่างซ่อมเสร็จ คุณกด "ใช้ได้แล้ว ปิดงาน" และให้ดาว — ถ้ายังไม่หาย กด "ยังไม่หาย" งานจะกลับไปที่ช่าง
ถ้าไม่กดยืนยันภายใน 3 วัน ระบบปิดงานให้อัตโนมัติ · เรื่องด่วนมาก (ทั้งแผนกใช้งานไม่ได้) โทรหาทีม IT ด้วย
ไปหน้าแจ้งซ่อม

ยืมอุปกรณ์ IT

โน้ตบุ๊ก โปรเจกเตอร์ และอุปกรณ์อื่นที่ IT เปิดให้ยืม — จองล่วงหน้าได้

  1. หน้าแรก กด "ยืมอุปกรณ์" → แท็บ "ยืมใหม่"
  2. ดู แถบสีใต้แต่ละเครื่อง (14 วันข้างหน้า): เขียว = ว่าง แดง = มีคนยืม — กดเลือกเครื่องที่ต้องการ (ดูสเปกได้ทางขวา)
  3. เลือก วันรับ – วันคืน (หรือ "ยืมระยะยาว ไม่มีกำหนดคืน") ใส่ว่าใช้ทำอะไร แล้วกด "ส่งคำขอยืม"
  4. รอ IT อนุมัติ แล้ว ไปรับของที่ห้อง IT ตามวันที่เลือก — เช็กของในชุดและ เซ็นรับบนจอ
  5. ครบกำหนด นำมาคืนที่ห้อง IT — ต้องการใช้ต่อ กด "ขอขยายเวลา" ที่แท็บ "ของที่ฉันยืม"
ตอนคืน IT จะล้างข้อมูลในเครื่องทั้งหมด (ตามมาตรฐาน TISAX) — สำรองไฟล์ของคุณก่อนคืน
ไปหน้ายืมอุปกรณ์

เบิกของ (เครื่องเขียน / ของแม่บ้าน)

เบิกได้เฉพาะของบริษัทตัวเอง · เลือกของใส่ตะกร้าเหมือนช้อปปิ้ง

  1. เปิดหน้า "เบิกของ" เลือก เครื่องเขียน หรือ ของแม่บ้าน (ค้นหาชื่อได้)
  2. กด "ใส่ตะกร้า" แล้วปรับจำนวน (+ / −) — ระบบบอกว่ามีให้เบิกกี่ชิ้น เบิกเกินไม่ได้
  3. ตรวจตะกร้าทางขวา ใส่หมายเหตุ (ถ้ามี) กด "ส่งใบเบิก"
  4. ติดตามที่ "ใบเบิกของฉัน": ส่งคำขอ → อนุมัติ → จัดของเสร็จ (พร้อมรับ) → รับของแล้ว
  5. ขึ้น พร้อมรับ ไปรับที่ผู้ดูแลสต็อก เซ็นรับ แล้วจบ — ถ้ารีบ มารับได้เลยไม่ต้องรอสถานะ
ผู้ดูแลอาจปรับจำนวนลง เช่น "ขอ 5 ได้ 3" (ของไม่พอ / เกินวงเงินแผนก) — ดูได้ในใบเบิกของฉัน
ไปหน้าเบิกของ

จองห้องประชุม

ทุกบริษัทจองได้ทุกห้อง · จองแล้วได้ห้องทันที (ยกเว้นห้องที่ต้องอนุมัติ)

  1. หน้าแรก กด "จองห้องประชุม" — ตารางแสดงทุกห้องทั้งวัน แถบสี = มีคนจองแล้ว (กดแถบเพื่อดูว่าใครจอง)
  2. เลือกวันที่ด้านบน แล้ว กดช่องว่างในแถวของห้อง ตรงเวลาที่ต้องการ — ระบบเลือกห้องและเวลาให้
  3. ใส่ เรื่องที่ประชุม (บังคับ) ปรับ วันที่/เวลาเริ่ม – สิ้นสุด (จองข้ามวันได้ เช่น อบรม 2 วัน)
  4. ไม่บังคับ: ประธานการประชุม (ถ้าจองแทนผู้บริหาร) · ผู้เข้าร่วม (พิมพ์ชื่อแล้วเลือกจากรายชื่อ) · มีแขกภายนอก · ขอให้เตรียม น้ำ/กาแฟ/อาหาร/โปรเจกเตอร์
  5. กด "จองห้อง" — ถ้ากรอกไม่ครบ ระบบบอกว่าขาดอะไร
  6. แก้เวลาหรือยกเลิกได้ที่แท็บ "การจองของฉัน" — ไม่ใช้แล้วกรุณายกเลิก คนอื่นจะได้จองต่อ
ห้องที่ขึ้น "ต้องอนุมัติ" (เช่น ห้องผู้บริหาร) จะเป็น รออนุมัติ จนผู้ดูแลห้องกดอนุมัติ
ไปหน้าจองห้อง

จองรถบริษัท

ทุกบริษัทจองรถได้ · ทุกใบต้องรอผู้ดูแลรถอนุมัติ · ใช้เสร็จต้องคืนกุญแจ

  1. หน้าแรก กด "จองรถ" — ตารางแสดงรถทุกคันทั้งวัน แถบสี = มีคนจองแล้ว
  2. กดช่องว่างในแถวของรถ ตรงเวลาที่จะออก หรือกดปุ่ม ช่วงเช้า / ช่วงบ่าย / ทั้งวัน
  3. ใส่ ไปทำอะไร กับ ไปที่ (บังคับ) · เลือก ขับเอง หรือ ขอคนขับ
  4. กด "ส่งคำขอจองรถ" — สถานะเป็น รออนุมัติ ดูได้ที่หน้าแรก "งานของฉัน"
  5. อนุมัติแล้ว รับกุญแจที่ผู้ดูแลรถ · ใช้เสร็จ นำกุญแจไปคืนผู้ดูแลรถ — ผู้ดูแลกดรับคืน ใบปิดเอง · ผู้ดูแลไม่อยู่: ฝากกุญแจแล้วกด "แจ้งคืนรถ" ที่ "การจองของฉัน"
รถคันเดียวกันจองเวลาทับกันไม่ได้ — ถ้าไปทางเดียวกัน กดแถบการจองนั้นแล้วเลือก "ขอติดรถไปด้วย" ชื่อคุณจะอยู่ในผู้ร่วมเดินทาง · จองให้คนอื่นได้ที่ช่อง "ผู้ใช้รถ"
ไม่ใช้แล้วกรุณากด "ยกเลิก" ก่อนเวลาออก คนอื่นจะได้จองต่อ · ออกรถแล้วยกเลิกไม่ได้ ต้องคืนรถ
ไปหน้าจองรถ

สำหรับผู้ดูแล

เห็นเมนูเหล่านี้เมื่อได้รับหน้าที่ในหน้า "สิทธิ์ผู้ใช้" · ดูแลเฉพาะบริษัทที่ได้รับมอบ

ผู้ดูแลสต็อก (เมนู สต็อก & เบิกของ)

  1. แท็บ คำขอ: กดใบเบิก → ปรับจำนวน → "อนุมัติ → จัดของ" → จัดเสร็จกด "จัดของเสร็จ" → พนักงานมารับ เซ็นรับ แล้วกด "จ่ายของ" (ตัดสต็อกตอนนี้)
  2. พนักงานยืนรออยู่: กด "อนุมัติและจ่ายเลย" ให้เซ็นแล้วจบในครั้งเดียว
  3. แท็บ คลังสินค้า: รับของเข้า (กรอกเป็นแพ็คหรือชิ้นได้) · นับสต็อก (พิมพ์ใบนับ → กรอกยอดจริง → ใส่เหตุผล) · เพิ่ม/แก้สินค้า · นำเข้า Excel

ผู้ดูแลห้องประชุม

  1. หน้าจองห้อง → แท็บ ผู้ดูแลห้อง: ดู "วันนี้ต้องเตรียม" เตรียมของตามที่ขอ แล้วกด "กดเมื่อเตรียมเสร็จ" · ห้องที่ต้องอนุมัติ กด อนุมัติ / ไม่อนุมัติ
  2. ตั้งค่า → ห้องประชุม: ห้องของบริษัท · กติกา (จองล่วงหน้าได้กี่วัน นานสุดกี่ชั่วโมง) · ของที่ให้ขอเตรียม · ห้องที่ต้องอนุมัติ

ผู้ดูแลรถ

  1. หน้าจองรถ → แท็บ ผู้ดูแลรถ → รออนุมัติ: กด อนุมัติ (ใบที่ขอคนขับ ให้เลือกคนขับ) หรือ ไม่อนุมัติ พร้อมเหตุผล — ส่วนใหญ่จองวันเดียวกับที่ใช้ อนุมัติให้เร็ว
  2. คนจองเอากุญแจมาคืน → แท็บ ใช้รถอยู่ / รับกุญแจคืน กด "รับกุญแจคืนแล้ว" ที่ใบนั้น จบ (หรือกดปุ่ม "รับกุญแจคืน" ในข้อความ LINE)
  3. แท็บ รถ / คนขับ: เพิ่ม/แก้รถ รูปรถ บริษัทเจ้าของ · รถที่ไม่ให้พนักงานจอง (เช่น รถผู้บริหาร) ให้ปิดการจอง

IT — ซ่อมไม่คุ้ม / ซื้อทดแทน

  1. งานช่าง IT → กด "ซ่อมไม่ได้" ติ๊ก "ซ่อมไม่คุ้ม — ทำใบประเมิน" → กรอกอายุเครื่อง ราคาเดิม ค่าซ่อมที่ประเมิน ราคาเครื่องใหม่ สาเหตุ → พิมพ์ใบประเมิน ให้หัวหน้าเซ็น
  2. หน้า ซ่อมไม่คุ้ม / ซื้อทดแทน: บันทึกผลอนุมัติ (ชื่อ + วันที่ตามใบ) → เลข PR/PO → ได้เครื่องใหม่ (ลงทะเบียนเครื่องใหม่ก่อน) → ใบติดตั้ง/มอบเครื่องใหม่ → ตัดจำหน่ายเครื่องเก่า (ล้างข้อมูล) → ปิดเรื่อง

IT — ยืม-คืนอุปกรณ์

  1. บอร์ด: อนุมัติคำขอ → วันรับของ เช็กของในชุด + ผู้ยืมเซ็นรับ → ตอนคืน เช็กของ เลือกสภาพเครื่อง ติ๊กล้างข้อมูลแล้ว + ผู้คืนเซ็น

คำถามที่พบบ่อย

ลืมรหัสผ่าน ทำอย่างไร

หน้าล็อกอิน กด "ลืมรหัสผ่าน" หรือแจ้งทีม IT

กดปุ่มแล้วไม่มีอะไรเกิดขึ้น / หน้าเก่า

กด Ctrl + Shift + R เพื่อโหลดหน้าใหม่ ถ้ายังไม่ได้ แจ้งซ่อม IT พร้อมแนบรูปหน้าจอ

จองห้องแล้วไม่ใช้ ต้องทำอะไร

ไปที่ "การจองของฉัน" กด "ยกเลิก" ห้องจะว่างให้คนอื่นทันที ถ้าขอให้เตรียมของไว้ ผู้ดูแลห้องจะได้รับแจ้งว่าไม่ต้องเตรียม

เบิกของไม่ได้ ขึ้นว่า "หมด"

ของหมดหรือถูกจองไว้แล้ว แจ้งผู้ดูแลสต็อกให้สั่งเพิ่ม

ทำไมเห็นแค่ของ/ห้องของบริษัทตัวเอง

เบิกของได้เฉพาะของบริษัทที่คุณล็อกอิน ส่วนห้องประชุม ตารางเปิดมาเป็นห้องของบริษัทคุณก่อน กดปุ่ม "ทุกบริษัท" เพื่อดูห้องอื่น (จองได้ทุกห้อง)

ใครเห็นข้อมูลที่ฉันกรอกบ้าง

ข้อมูลอยู่ในระบบภายในบริษัท เปิดได้เฉพาะคนที่ล็อกอิน และเห็นตามหน้าที่ เช่น ช่าง IT เห็นงานซ่อม ผู้ดูแลสต็อกเห็นใบเบิก (ตามมาตรฐาน TISAX)

ไม่เจอคำตอบ?

แจ้งทีม IT ได้เลย แนบรูปหน้าจอมาด้วยจะช่วยให้แก้ได้เร็วขึ้น
