## Notebook (NB)

เครื่องพกพา — มอบให้พนักงาน / ยืม / สลับมือบ่อย

| ฟิลด์ | ในระบบ | ระดับ | หมายเหตุ |
|-------|--------|-------|----------|
| Serial Number | มี | **R** | ตรวจกับฝากล่อง/BIOS |
| **PC Name / Hostname** | **ยังไม่มี** | **R** | เก็บใน `setup.html` อย่างเดียว — ควรย้ายมาทะเบียน |
| IP Address | มี | Rec | ถ้าใช้ LAN คงที่ |
| MAC Address | มี | Rec | Wi‑Fi + LAN ถ้ามี 2 ตัว ใส่ใน spec |
| สเปค (spec_details) | มี | **R** | CPU / RAM / SSD ขั้นต่ำ |
| OS + Version | ไม่มีฟิลด์เฉพาะ | **R** | ใส่ใน spec จนกว่าจะมีฟิลด์แยก |
| ผู้ถือครอง + แผนก | มี | **R** | |
| Allow Loan | มี | Opt | ติ๊กถ้าเข้า pool ยืม |
| อุปกรณ์เสริม | มี | Rec | สายชาร์จ, กระเป๋า, Mouse |
| รูปภาพ | มี | **R** | มุม S/N ชัด + ภาพรวม |

**ก่อนปิดงานมอบเครื่อง:** Asset ID + S/N + Hostname + ผู้ถือครอง + รูป + สเปค/OS

## Checklist ก่อน Deploy / Go-live ทะเบียน

ใช้ตรวจทั้งองค์กร (Inspector แนะนำ)

- [ ] ทุก **Notebook/PC ที่มอบแล้ว** มี Asset ID + S/N
- [ ] ทุกเครื่องที่ใช้งานมี **ผู้ถือครอง + Location**
- [ ] PC Set ใช้ **parent/child** ไม่แยกจอลอยโดยไม่จำเป็น
- [ ] รูปถ่าย + S/N ครบสำหรับเครื่องมูลค่าสูง
- [ ] เลขทะเบียนบัญชี (ถ้ามี) ตรงกับฝ่ายพัสดุ
- [ ] ไม่มีสถานะ “ใช้งานปกติ” แต่ไม่มีผู้ถือครอง (ยกเว้น pool สำรอง)
- [ ] ข้อมูลใน **setup onboarding** ถูก copy/ref มาทะเบียน (จนกว่าจะ sync อัตโนมัติ)

## ช่องว่างระบบ (รอ Dev แก้)

| ลำดับ | เรื่อง | ผลกระทบ |
|-------|--------|---------|
| 1 | ไม่มีฟิลด์ **Hostname** ใน admin | ตามเครื่องในเครือข่ายยาก |
| 2 | ผู้ถือครองไม่ผูก **employee_id** | รายงาน/ directory ไม่ match |
| 3 | **setup.html** ไม่ sync → `it_assets` | ข้อมูลซ้ำ/ขาด |
| 4 | ไม่บังคับฟิลด์ตามหมวด | ข้อมูลไม่ครบแต่บันทึกได้ |
