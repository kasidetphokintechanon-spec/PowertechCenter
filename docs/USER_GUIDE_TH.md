## 1. เริ่มต้นใช้งาน

### เข้าสู่ระบบ

1. เปิด `login.html`
2. กรอก Username / Password ที่ HR หรือ IT ออกให้
3. เลือกบริษัท (ถ้ามีหลายสังกัด)
4. กดเข้าสู่ระบบ

### ออกจากระบบ

ปุ่มออกจากระบบที่มุมขวาบนของหน้าแรก

### โหมดมืด (Dark mode)

ปุ่มดวงจันทร์ที่แถบบน — การตั้งค่าจำในเครื่อง

### ไอคอนบน Desktop ที่โผล่มาเอง

ถ้าเปิดเครื่องมาแล้วเห็นไอคอน **"Powertech System Center"** และ **"Contact List"** อยู่ที่ Desktop โดยไม่เคยกด Install เอง — ไม่ใช่ไวรัสหรือความผิดพลาด ไอที่ตั้งค่าให้ระบบติดตั้งลิงก์เข้าใช้งานให้อัตโนมัติทุกเครื่อง เพื่อความสะดวก ไม่ต้องพิมพ์ URL เอง:

- **Powertech System Center** → เปิดหน้าเข้าสู่ระบบ (เหมือนเปิด `login.html` ผ่าน browser ปกติ)
- **Contact List** → เปิดหน้ารายชื่อพนักงานโดยตรง (ไม่ต้อง login)

ไอคอนทั้ง 2 ถูกตั้งไว้โดยฝ่าย IT (ผ่าน Group Policy) จึงลบเองไม่ได้ — ถ้าไม่ต้องการเห็นบน Desktop ให้ติดต่อฝ่าย IT

## 7. คลังสินค้า

ระบบคลังสินค้าแบ่งเป็น 2 ประเภทสินค้า และมีขั้นตอน workflow 5 ขั้นตอน:

> **1) สร้างคำขอ → 2) ส่งอนุมัติ → 3) ติดตามผล/พิมพ์ใบ → 4) จ่ายของ/คืน/ปรับสต็อก → 5) รายงานย้อนหลัง**

---

### 7.1 เบิกของแม่บ้าน

**ไฟล์:** `maid_stock.html`  
**สำหรับ:** พนักงานฝ่ายแม่บ้าน / General Services

**ขั้นตอน:**

1. เลือกบริษัท (PTA / PT4 / PTE) และหมวดสินค้า (ทำความสะอาด / ผ้า-ขจัดสี / อื่นๆ)
2. กด **+** หรือ **+ เพิ่มในรายการ** เพื่อเพิ่มสินค้าลงตะกร้า
3. กรอก **เหตุผลการเบิก** ในช่องทางขวา (เช่น "ทำความสะอาดพื้นที่ส่วนกลาง")
4. กด **ส่งคำขออนุมัติ** → ระบบสร้างเลขที่คำขอ (เช่น PTA-HQ-260601)
5. กด **พิมพ์ใบเบิก** เพื่อพิมพ์ใบขอเบิก (FM-MS-001) ได้ทันที

> สินค้าที่แสดง **หมดสต็อก** ไม่สามารถเพิ่มได้ — แจ้งเจ้าหน้าที่คลังเพื่อเติมสินค้า

---

### 7.2 เบิกเครื่องเขียน / วัสดุสิ้นเปลือง

**ไฟล์:** `stationery.html`  
**สำหรับ:** พนักงานทุกแผนก

**ขั้นตอน:** เหมือน 7.1 ทุกประการ แต่ใช้หมวดสินค้าสำนักงาน / IT / ความปลอดภัย / อื่นๆ  
ใบขอเบิกใช้เลขแบบฟอร์ม **FM-SN-001**

> แนบเอกสารประกอบได้ (เช่น ใบขออนุมัติโครงการ) ในช่องแนบเอกสารก่อนส่ง

### 7.3 ประวัติและติดตามคำขอ

**ไฟล์:** `my_stock_history.html`  
**เข้าถึงได้จาก:** ปุ่ม **ประวัติ** มุมขวาบนในหน้าเบิกสินค้า

| ฟังก์ชัน | วิธีใช้ |
|----------|---------|
| ดูสถานะ | กรองด้วยแท็บ รออนุมัติ / อนุมัติแล้ว / ปฏิเสธ |
| พิมพ์ใบเบิก | กดปุ่ม **พิมพ์** ในแต่ละรายการ — เปิดใบขอเบิก ISO |
| แก้ไขคำขอ | ได้เฉพาะคำขอที่ยัง **รออนุมัติ** |
| ยกเลิก | กด **ยกเลิกคำขอ** — ไม่สามารถกู้คืนได้ |

**ใบขอเบิก (ISO)** ที่พิมพ์ได้ประกอบด้วย:
- เลขที่เอกสาร, บริษัท, ผู้ขอเบิก, แผนก, วันที่
- ตารางรายการสินค้า (รหัส / ชื่อ / จำนวนขอ / จำนวนจ่าย)
- ช่องลายเซ็น 3 ช่อง: ผู้ขอเบิก / หัวหน้าแผนก / ผู้จ่ายของ
- ISO Control: Form No., Revision, Eff. Date + QR Code

### 7.4 การอนุมัติ (Admin / GA)

**ไฟล์:** `stock_management.html`  
**สิทธิ์:** `stock.manage` หรือ `role = admin`

**ขั้นตอนอนุมัติ:**

1. เข้า **คำขออนุมัติ** → เลือก **เครื่องเขียน** หรือ **แม่บ้าน**
2. คำขอที่รอดำเนินการแสดงในแท็บ **รอดำเนินการ**
3. กดคำขอเพื่อดูรายละเอียด — ระบบแสดงสต็อกคงเหลือและ **หลังตัด** อัตโนมัติ
4. ปรับจำนวนอนุมัติได้ (ถ้าสต็อกไม่พอ)
5. เลือก:
   - **อนุมัติและจ่ายออก** → สต็อกลดทันที, สร้างรายการเคลื่อนไหว
   - **ปฏิเสธคำขอ** → ระบุเหตุผล
   - **ข้ามไปตัดไป** → ดำเนินการภายหลัง

**หลังอนุมัติ:** กดคำขอในแท็บ **อนุมัติแล้ว** → มีปุ่ม 2 ตัว:
- **พิมพ์ใบเบิก (ISO)** — เปิด `print_stock.php` แสดงใบเบิกพัสดุ (FM-STK-001 Rev.02)
- **พิมพ์แบบเดิม** — ใบเบิกรูปแบบย่อสำหรับใช้ภายใน

### 7.5 หน้ารายงาน

**ไฟล์:** `stock_management.html` → เมนู **รายงาน**

| Tab | เนื้อหา |
|-----|---------|
| **รายงานรายเดือน** | สรุปยกมา / รับเข้า / เบิกออก / คงเหลือ + ตารางรายสินค้า พร้อม Export CSV / Excel / พิมพ์ |
| **ประวัติรายการ** | Audit trail ทุก transaction (เบิก/รับ/ปรับ) พร้อมผู้ทำรายการและผู้อนุมัติ |
| **ประวัติคำขอ** | รายการคำขอทั้งหมด กรองด้วยวันที่และสถานะ กดแถวเพื่อดูรายละเอียด |
| **สถิติ** | Top 10 สินค้าเบิกมากที่สุด + สรุปยอดรวมรับ/เบิก/คืน/ปรับ |

> เลือก **ปี + เดือน** และกด **ดูรายงาน** เพื่อโหลดข้อมูล  
> กรองบริษัท (PTA/PT4/PTE) และประเภทสินค้า (เครื่องเขียน/แม่บ้าน) ที่แท็บด้านบน

### 7.6 วงเงินแผนก (Quota)

**ไฟล์:** `stock_management.html` → เมนู **ตั้งค่า** → **วงเงินแผนก**  
**สิทธิ์:** `stock.manage` หรือ `role = admin`

ระบบรองรับการตั้งวงเงิน **2 มิติ** ต่อแผนก/บริษัท/ประเภทสินค้า/เดือน:

| มิติ | ช่อง | ความหมาย |
|------|------|-----------|
| **วงเงิน qty** | รายการ/เดือน | จำนวนรายการสูงสุดที่แผนกเบิกได้ |
| **วงเงิน ฿** | บาท/เดือน | งบประมาณสูงสุดที่แผนกใช้ได้ (คำนวณจาก qty × ราคา/หน่วย) |

> **0 = ไม่จำกัด** — ทั้งสองมิติ

**วิธีตั้งค่า:**
1. เลือกบริษัทและประเภทสินค้าที่ filter ด้านบน
2. แต่ละแถวคือ 1 แผนก — กรอกจำนวนในช่อง **วงเงิน qty** และ/หรือ **วงเงิน ฿**
3. กดปุ่ม **บันทึก** ที่ปลายแถวของแผนกนั้น

**การแสดงผล:** แถบความคืบหน้าแสดงสีตามเปอร์เซ็นต์ที่ใช้ไป
- 🟢 เขียว — ใช้ไปน้อยกว่า 80%
- 🟡 เหลือง — ใช้ไป 80–99%
- 🔴 แดง — ใช้ครบหรือเกิน 100%

> **หมายเหตุ:** มูลค่า (฿) คำนวณจากราคา/หน่วยของสินค้าในระบบ — ควรตั้งราคาสินค้าใน Catalog ให้ครบก่อนเพื่อให้ตัวเลขถูกต้อง

## 9. Admin Panel

**ไฟล์:** `admin.html`  
**เข้าได้เมื่อ:** `role = admin` หรือมีสิทธิ์ `admin.access_admin` + สิทธิ์ย่อยตามเมนู

### บัญชี Admin เต็ม (`role = admin`)

ใช้ได้ **ทุกเมนู** ใน Admin รวมถึง:

- จัดการพนักงาน / แผนก / ตำแหน่ง
- พัสดุ IT
- บริการบนหน้าแรก (ลิงก์ + URL สำรอง)
- KB / ประกาศ / วันหยุด
- สิทธิ์ผู้ใช้
- แจ้งเตือน Telegram / LINE
- Backup / Audit

### บัญชีที่มีเฉพาะ "เข้า Admin"

เห็นหน้า Admin แต่เมนูที่ไม่มีสิทธิ์จะ **กดไม่ได้** — ติดต่อ IT ให้เพิ่มสิทธิ์ในแท็บ Permissions
