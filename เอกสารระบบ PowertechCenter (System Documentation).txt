 เอกสารระบบ PowertechCenter (System Documentation)
1. ภาพรวมระบบ (System Overview)
ชื่อระบบ: PowertechCenter (Intranet Portal)
เป้าหมาย: ระบบบริหารจัดการภายในองค์กรแบบรวมศูนย์ รองรับการจองห้องประชุม, แจ้งซ่อม (Ticket), ยืม-คืนอุปกรณ์, ทะเบียนทรัพย์สิน และข้อมูลพนักงาน
ผู้ใช้งาน:
User: พนักงานทั่วไป (จองห้อง, แจ้งซ่อม, ดูประวัติ)
Staff: เจ้าหน้าที่ IT/Facilities (จัดการงานซ่อม, อนุมัติการจอง/ยืม)
Admin: ผู้ดูแลระบบ (จัดการสิทธิ์, ตั้งค่าระบบ, แก้ไขข้อมูลหลัก)
Tech Stack:
Frontend: HTML5, CSS (TailwindCSS), JavaScript (Vanilla + SweetAlert2, FullCalendar, Chart.js)
Backend: PHP (Native + Modular Actions via api.php)
Database: MySQL / MariaDB (powertech_system)
Real-time: WebSocket (Node.js ws library)
Integrations: LINE Notify/Messaging API, Telegram Bot

3. สคีมาฐานข้อมูล (Database Schema)
Database Name: powertech_system
ตารางหลัก:
employees: ข้อมูลพนักงาน, Login, Role (admin, staff, user).
it_assets: ทะเบียนทรัพย์สิน IT, สถานะ (ว่าง, ใช้งานปกติ, ส่งซ่อม), is_loanable.
bookings: การจองห้องประชุม (start_time, end_time, status, room_id).
it_logs (Job Tickets): ใบงานแจ้งซ่อม (problem, solution, status, servicedBy).
it_loan_history: ประวัติการยืม-คืน พร้อมลายเซ็น (borrower_signature).
meeting_rooms: ข้อมูลห้องประชุมและอุปกรณ์ภายใน.
4. โปรโตคอล API (API Contracts)
ระบบใช้รูปแบบ Action-based API ผ่าน api.php

Endpoint: POST /api.php หรือ GET /api.php
Parameter บังคับ: action (เช่น login, create_booking, get_pending_counts)
Authentication: PHP Session + Cookie remember_token
Response Format:
json
{
  "status": "success" | "error",
  "message": "...",
  "data": { ... }
}
5. โฟลว์งานหลัก (Workflows)
จองห้องประชุม:
User เลือกเวลา/ห้องใน booking_v2.html -> api?action=create_booking
สถานะเริ่มต้น Pending (หรือ Confirmed ตามตั้งค่า)
Staff อนุมัติใน approve_booking.html -> ระบบส่งแจ้งเตือน LINE/Telegram
แจ้งซ่อม (Ticket):
User แจ้งปัญหา -> สถานะ Pending
Staff รับงาน (In Progress) -> ดำเนินการ/รออะไหล่ -> ปิดงาน (Completed)
User ให้คะแนนความพึงพอใจ (Rating)
ยืม-คืนอุปกรณ์:
User ขอยืม -> Staff อนุมัติ (LOAN_APPROVED)
รับของ: เซ็นชื่อรับ (borrower_signature) -> สถานะ Active
คืนของ: Staff ตรวจรับและเซ็นชื่อ (return_approver_signature) -> สถานะ Completed
