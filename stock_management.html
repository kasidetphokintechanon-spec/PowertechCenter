1. วัตถุประสงค์ (Purpose)

เอกสารนี้กำหนดขั้นตอนการปฏิบัติงานสำหรับการ จัดการคลังพัสดุสำนักงาน ครอบคลุมตั้งแต่การตั้งค่าระบบ รับของเข้า การขอเบิก-อนุมัติ-จ่ายของออก จนถึงการนับสต็อกและรายงาน เพื่อให้:

มีหลักฐานการเบิกจ่ายทุกครั้ง — สอดคล้อง ISO Audit Trail

6. เพิ่มสินค้าใหม่เข้าระบบ (ครั้งแรก)
Stock → แท็บ "รายการสินค้า" → ปุ่ม "+ เพิ่มสินค้า"
กรอกข้อมูลสินค้า
• ชื่อสินค้า เช่น ถ่าย 2A
• หน่วย เช่น แพค
• ราคา/หน่วย เช่น 50
• หมวดหมู่ และบริษัท
ตั้งค่า Min / Max Stock
• Min = แจ้งเตือนเมื่อต่ำกว่าค่านี้
• Max = เป้าหมายสต็อกที่ควรมี
• เช่น Min 5 Max 50
สินค้าที่เพิ่งสร้าง ยอดจะเป็น 0 — ต้องไปตั้งยอดเปิดบัญชีหรือรับของเข้าต่อ
7. ตั้งยอดเปิดบัญชี
ใช้ครั้งแรกที่เริ่มใช้ระบบ — กรณีมีของอยู่แล้วแต่ยอดระบบยังเป็น 0
Stock → แท็บ "ตั้งยอดเปิดบัญชี" → กรอกจำนวน → "บันทึก"
กรอกจำนวนของที่มีอยู่จริงในคลัง ณ วันที่เริ่มใช้ระบบ ระบบจะบันทึกเป็น transaction ประเภท "opening balance"
8. รับของเข้าสต็อก (ใช้ทุกครั้งที่ซื้อของมา)
1 รับทีละชิ้น (ใช้บ่อยที่สุด)
ไปที่ Stock → ยอดคงเหลือ → คลิกชื่อสินค้า → panel ขวาเปิดขึ้น → กด "รับเข้า"
กรอก: จำนวนที่รับ + ราคาต่อหน่วยล็อตนี้ + หมายเหตุ → "บันทึกรับสินค้า"
ระบบคำนวณราคาถัวเฉลี่ยอัตโนมัติ (Weighted Average)
มีอยู่ 10 แพค @ 50฿ (500฿) + รับเพิ่ม 5 แพค @ 55฿ (275฿)
ราคาใหม่ = 775 ÷ 15 = 51.67฿/แพค ← ระบบคำนวณให้อัตโนมัติ ไม่กระโดดพรวดเดียว
2 รับของหลายชิ้นพร้อมกัน (Bulk Receive)
Stock → แท็บ "รับของเข้ากลุ่ม"
เหมาะตอนซื้อของหลายอย่างในใบสั่งซื้อเดียว → เลือกสินค้า + จำนวน + ราคา ทีละแถว → "บันทึกทั้งหมด"
9. ขั้นตอนการขอเบิก (สำหรับพนักงาน)
ทำผ่านหน้า ขอเบิกพัสดุ (request.html)
1
เปิดหน้าขอเบิก
ไปที่ request.html → เลือกแท็บ เครื่องเขียน หรือ แม่บ้าน → กด "ขอเบิก"
2
เลือกสินค้าและจำนวน
เลือกสินค้าจากรายการ ระบุจำนวนที่ต้องการ และใส่เหตุผลการเบิก
3
ส่งคำขอ → รอการอนุมัติ
กด "ส่งคำขอ" — ระบบส่งแจ้งเตือนไปยัง Admin ทาง LINE อัตโนมัติ
4
ตรวจสอบสถานะ
ดูสถานะใน ประวัติการเบิก (my_stock_history.html) — เห็นผลว่า อนุมัติ / ปฏิเสธ พร้อมเหตุผล
10. ปรับแก้ยอดสต็อก (กรณีนับแล้วไม่ตรง)
คลิกสินค้าใน ยอดคงเหลือ → panel ขวา → กด "ปรับสต็อก"
ใส่ตัวเลข: +3 = เพิ่ม 3 ชิ้น  |  -2 = ลด 2 ชิ้น
ต้องใส่เหตุผลทุกครั้ง เช่น "นับสต็อกประจำเดือน พบของหาย 2 ชิ้น"
11. อนุมัติคำขอเบิก (Admin)
เมนู "คำขอรออนุมัติ" → เลือกแท็บ เครื่องเขียน หรือ แม่บ้าน
กดรายการเพื่อดูรายละเอียด — ระบบแสดงสต็อกคงเหลือและ ยอดหลังตัด ให้อัตโนมัติ
ปรับจำนวนอนุมัติได้ (กรณีสต็อกไม่พอ) → เลือก:
อนุมัติและจ่ายออก — สต็อกลดทันที สร้าง transaction บันทึกใน audit trail
ปฏิเสธคำขอ — ระบุเหตุผล ผู้ขอเบิกเห็นใน my_stock_history
ข้ามไปตัดไป — เก็บไว้ดำเนินการภายหลัง
พิมพ์ใบเบิกหลังอนุมัติ
กดคำขอในแท็บ อนุมัติแล้ว → มีปุ่ม 2 ตัว:
  • พิมพ์ใบเบิก (ISO) — เปิดใบเบิกพัสดุ มาตรฐาน ISO ครบ (FM-STK-001 Rev.02)
    ประกอบด้วย: ข้อมูลผู้ขอ, ตารางสินค้า, ช่องลายเซ็น 3 ช่อง (ผู้ขอ / ผู้จ่าย / ผู้อนุมัติ)
  • พิมพ์แบบเดิม — ใบย่อสำหรับใช้ภายใน
12. นับสต็อก — Physical Count
ทำทุกสิ้นเดือนหรือเมื่อสงสัยว่ายอดไม่ตรง
เมนูซ้าย "นับสต็อก" หรือ Stock → แท็บ นับสต็อก
1
เตรียมใบนับสต็อก
ระบบแสดงรายการสินค้าทั้งหมดพร้อมยอดในระบบ — พิมพ์ออกมาใช้นับ หรือนับผ่านหน้าจอโดยตรง
2
กรอกจำนวนที่นับได้จริง
ใส่ ยอดนับจริง ลงในช่อง — ระบบคำนวณส่วนต่าง (+/-) ให้อัตโนมัติ
3
ตรวจสอบส่วนต่าง
รายการที่มีส่วนต่างจะถูก Highlight — ใส่หมายเหตุสาเหตุที่ไม่ตรง เช่น "สูญหาย" หรือ "นับผิด"
4
ยืนยันการปรับยอด
กด "ยืนยันและปรับยอด" — ระบบบันทึก Adjustment transaction พร้อมหมายเหตุ ตรวจสอบย้อนหลังได้ใน Audit Trail
ควรนับสต็อก ก่อนรับของชุดใหม่ และ ทุกสิ้นเดือน — ทุก Adjustment มี Audit Trail บันทึกไว้เสมอ
13. หน้ารายงาน
รายงานรายเดือน
สรุปยกมา / รับเข้า / เบิกออก / คงเหลือ รายสินค้าทุกชิ้น พร้อม Export CSV / Excel / พิมพ์
ประวัติรายการ
Audit trail ทุก transaction — เบิก/รับ/ปรับ พร้อมผู้ทำรายการและผู้อนุมัติ กรองด้วยวันที่และประเภท
ประวัติคำขอ
รายการคำขอทั้งหมด กรองสถานะ/วันที่ กดแถวดูรายละเอียดและพิมพ์ใบเบิกซ้ำได้
สถิติ
Top 10 สินค้าเบิกมากที่สุด + สรุปยอดรวมรับ/เบิก/คืน/ปรับ ช่วงเวลาที่เลือก
เลือก ปี + เดือน แล้วกด "ดูรายงาน" — กรองบริษัทและประเภทสินค้าที่แท็บด้านบนก่อนดูรายงาน
14. สัญญาณเตือนที่ต้องระวัง
🔴
แถวสีแดง — ของต่ำกว่า Min Stock → รีบสั่งซื้อ
🟡
แถวสีเหลือง — ของใกล้ถึง Min Stock → เตรียมสั่งซื้อ
🔔
ป้ายแจ้งเตือนด้านบน — มีหลายรายการต่ำกว่า Min → เช็ค Dashboard
15. วงเงินแผนก (Quota)
ตั้งจำกัดการเบิกรายแผนกต่อเดือน — ทั้ง qty และวงเงินบาท
เมนูซ้าย "ตั้งค่า" → "วงเงินแผนก"
วงเงิน qty (รายการ/เดือน)
ตั้งจำนวนรายการสูงสุดที่แผนกเบิกได้ต่อเดือน
0 = ไม่จำกัด
ตัวอย่าง: IT ได้ 50 รายการ/เดือน
วงเงินบาท (฿/เดือน)
ตั้งงบประมาณสูงสุดที่แผนกใช้ได้ต่อเดือน
0 = ไม่จำกัด
ตัวอย่าง: Production ได้ 5,000 บาท/เดือน
แถวแต่ละแผนกมี แถบความคืบหน้า แสดง qty ที่ใช้ไปเทียบวงเงิน และมูลค่า (฿) ที่ใช้ไปเทียบงบประมาณ
สีแถบ: เขียว (<80%) → เหลือง (80–99%) → แดง (≥100%)
มูลค่าคำนวณจาก ราคา/หน่วย ของสินค้าแต่ละชิ้น (price_per_unit) × จำนวนที่อนุมัติ — หากสินค้าบางรายการยังไม่ได้ตั้งราคา มูลค่าจะต่ำกว่าความเป็นจริง ควรตั้งราคาสินค้าใน Catalog ให้ครบก่อน
