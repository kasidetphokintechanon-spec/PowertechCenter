ขั้นตอนการติดตั้งและใช้งาน

1

ติดตั้งลงเครื่อง (Client Side)

นำไฟล์ .reg ที่ดาวน์โหลดไปไว้ที่เครื่องคอมพิวเตอร์ที่ต้องการใช้งาน

ดับเบิลคลิกที่ไฟล์ แล้วกด Yes (หรือ OK) เพื่อยืนยันการเพิ่มค่าลงใน Registry

* ต้องใช้สิทธิ์ Administrator ของเครื่องนั้นๆ

2

ตั้งค่าในระบบ (Admin Side)

ไปที่เมนู Admin > Services แล้วกด "เพิ่มรายการ"

ในช่อง Primary URL ให้ใส่ค่านี้:

Tip: หาก Path ของโปรแกรมในแต่ละเครื่องไม่เหมือนกัน จำเป็นต้องสร้างไฟล์ .reg แยกสำหรับแต่ละเครื่อง หรือติดตั้งโปรแกรมไว้ที่ Path เดียวกันทุกเครื่อง (เช่น C:\Apps\...)
