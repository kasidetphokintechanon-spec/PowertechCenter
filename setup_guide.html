1. วัตถุประสงค์ (Purpose)

เอกสารนี้กำหนดขั้นตอนการปฏิบัติงานสำหรับฝ่าย IT ในการ ติดตั้งคอมพิวเตอร์และให้สิทธิ์การเข้าถึงระบบแก่พนักงานใหม่ (Onboarding) และ ถอนสิทธิ์และรับคืนอุปกรณ์เมื่อพนักงานสิ้นสุดการจ้างงาน (Offboarding) เพื่อให้มั่นใจว่า:

ข้อมูลและระบบของบริษัทได้รับการปกป้อง — สอดคล้อง TISAX (Information Security)
การจัดการสิทธิ์ผู้ใช้เป็นไปอย่างมีระบบ — สอดคล้อง IATF 16949 (Document & Record Control)
มีหลักฐานเป็นลายลักษณ์อักษรทุกขั้นตอน พร้อมให้ตรวจสอบโดย Auditor
2. ขอบเขตการใช้งาน (Scope)
ใช้กับ พนักงานทุกคนของ PTA · PT4 · PTE ที่ได้รับหรือคืนอุปกรณ์คอมพิวเตอร์
ครอบคลุม คอมพิวเตอร์ตั้งโต๊ะ, โน้ตบุ๊ก, และอุปกรณ์ IT ที่บริษัทจัดให้
ระบบที่เกี่ยวข้อง Windows Login · Internet / Fortigate · VPN · ERP · MRP · เครื่องพิมพ์ · PowertechCenter
ผู้รับผิดชอบ ฝ่าย IT — Information Technology
เอกสารอ้างอิง IT-FM-001 (ใบส่งมอบฯ) · IT-FM-002 (ใบถอนสิทธิ์ฯ)
3. ผู้รับผิดชอบ (Responsibility)
ช่าง IT (IT Technician)
ดำเนินการติดตั้ง กรอกข้อมูล ตรวจสอบ checklist และส่งมอบเครื่อง
หัวหน้า IT
ตรวจสอบความครบถ้วน อนุมัติการเปิด/ปิดสิทธิ์ระบบสำคัญ
พนักงาน (End User)
รับมอบเครื่อง ลงนามยืนยัน และปฏิบัติตามนโยบาย IT ของบริษัท
HR / หัวหน้าแผนก
แจ้ง IT เมื่อมีพนักงานเข้าใหม่หรือลาออก พร้อมระบุสิทธิ์ที่ต้องการ

5. ขั้นตอน Onboarding (การรับพนักงานใหม่)
1
รับข้อมูลพนักงานจาก HR
รับแจ้งชื่อ-สกุล, แผนก, บริษัท (PTA/PT4/PTE), วันเริ่มงาน
ตรวจสอบว่าต้องการสิทธิ์ระบบใดบ้าง (Internet, VPN, ERP, MRP)
2
เตรียมเครื่องคอมพิวเตอร์
ติดตั้ง Windows, Driver, Software ตามมาตรฐาน IT
บันทึก Asset Code, Serial Number, PC Name, IP Address
Windows 10/11 Driver ครบ Antivirus Office Join Domain Remote Desktop
3
สร้าง Account และให้สิทธิ์ระบบ
สร้าง Windows Login รูปแบบ Firstname.L (เช่น Anan.A)
Password เริ่มต้น = รหัสพนักงาน (ใช้ร่วมกันทุกระบบ)
Internet / Fortigate VPN (FortiClient) ERP / MRP เครื่องพิมพ์ PowertechCenter
4
กรอก Setup Checksheet setup.html
เปิด setup.html → กรอกข้อมูลพนักงาน, เครื่อง, สิทธิ์การเข้าถึง
ทำ Checklist ให้ครบทุกข้อ → กด บันทึก
5
ส่งมอบเครื่องและรับลายเซ็น IT-FM-001
กด พิมพ์ จาก setup.html → ได้เอกสาร IT-FM-001
ให้พนักงานและช่าง IT ลงนาม → เก็บสำเนาไว้ 1 ชุด
6
ส่ง Email แจ้ง Account
กด สร้างอีเมล จาก setup.html → copy ข้อความ → ส่งหา Manager หรือ HR
อีเมลจะระบุ: Windows Login, Internet/VPN, ระบบที่ได้สิทธิ์, รหัสเครื่องพิมพ์
6. ขั้นตอน Offboarding (การถอนสิทธิ์และรับคืนเครื่อง)
สำคัญ: ต้องดำเนินการถอนสิทธิ์ ภายในวันที่พนักงานสิ้นสุดการจ้างงาน เพื่อป้องกันการเข้าถึงระบบโดยไม่ได้รับอนุญาต
1
รับแจ้งจาก HR / หัวหน้าแผนก
ยืนยันวันสุดท้ายของการทำงาน, รายการเครื่องที่ต้องคืน
2
ค้นหา Record ใน Setup List setup_list.html
เปิด setup_list.html → ค้นชื่อพนักงาน → กดปุ่ม Offboard
3
ถอนสิทธิ์ทุกระบบ
ทำตาม Offboard Checklist — ถอนครบทุกบริษัทที่มีสิทธิ์
ตรวจสอบจากข้อมูล Internet/VPN ที่บันทึกไว้ตอน Onboard ว่ามี PTA/PT4/PTE ไหนบ้าง
Disable AD Account ถอน Internet/Fortigate ถอน VPN ถอน ERP/MRP ถอนสิทธิ์พิมพ์ คืน Email
4
รับคืนอุปกรณ์
รับคืนเครื่อง, Charger, อุปกรณ์เสริม → ตรวจสอบสภาพ → บันทึกหมายเหตุ
5
กรอก Offboard Checksheet และรับลายเซ็น IT-FM-002
กด พิมพ์ จาก setup_offboard.html → ได้เอกสาร IT-FM-002
ให้พนักงานและช่าง IT ลงนาม → เก็บสำเนาไว้ 1 ชุด
7. มาตรฐาน Account และ Password
Windows Login Firstname.L — ชื่อจริง + จุด + อักษรแรกของนามสกุล (ตัวใหญ่)
ตัวอย่าง: นายอนันต์ อาจหาญ → Anan.A
Internet / VPN Username = ชื่อจริงเท่านั้น (ไม่มี .นามสกุล)
ตัวอย่าง: Anan
Password ทุกระบบ รหัสพนักงาน (ใช้ร่วมกัน: Internet · VPN · ERP · MRP · เครื่องพิมพ์)
PowertechCenter Username = รหัสพนักงาน / Password = รหัสพนักงาน
แนะนำให้พนักงานเปลี่ยน Password หลังจากล็อกอินครั้งแรก โดยเฉพาะระบบ ERP และ VPN
