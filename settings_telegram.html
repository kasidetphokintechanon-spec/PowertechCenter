หมายเหตุเรื่อง SSL/Proxy
หากทดสอบไม่ผ่าน ให้ตรวจสอบว่าเครื่องออก Internet ได้และผ่านการล็อกอินเครือข่าย (เช่น Net Login/FortiGate) แล้ว รวมถึงกรณีมี SSL Inspection/Proxy อาจทำให้ขึ้น error เรื่อง certificate subject name ไม่ตรงกับ api.telegram.org

วิธีการหาค่า Token และ Chat ID

1

สร้าง Bot: ค้นหา @BotFather ใน Telegram พิมพ์ /newbot แล้วทำตามขั้นตอนเพื่อรับ Bot Token

2

สร้างกลุ่ม: สร้างกลุ่มใหม่แล้วเชิญ Bot ที่สร้างเมื่อกี้เข้ากลุ่ม

3

หา Chat ID: ส่งข้อความในกลุ่ม แล้วเปิด URL นี้ในเบราว์เซอร์:

https://api.telegram.org/bot[YOUR_TOKEN]/getUpdates

หาคำว่า "chat":{"id": ตัวเลขที่ตามมาคือ Chat ID (ถ้าเป็นกลุ่มจะมีเครื่องหมายลบนำหน้า)
